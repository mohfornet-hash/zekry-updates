إرسال مباشر إلى GitHub

يمكن فتح هذا الملف من جهازك. لا يحتاج Vercel أو Supabase أو تسجيل الدخول إلى غرفة التحكم.

إعداد مفتاح الإرسال لأول مرة
  1. افتح إنشاء Fine-grained token على GitHub.
  2. اختر الحساب mohfornet-hash ثم Only select repositories وحدد zekry-updates فقط.
  3. في Repository permissions اجعل Contents بصلاحية Read and write، وحدد مدة صلاحية مناسبة.
  4. اضغط Generate token والصقه في خانة مفتاح GitHub أدناه. لا تضعه داخل update.json ولا ترسله في المحادثة.

النسخة المرتبطة الحالية: 20.55.977، ورقمها 206378. انشر APK الحقيقي أولًا، ثم استخدم رقمًا أكبر للنسخة التالية. قد يحتاج ظهور التعديل بضع دقائق.

يتم تعديل update.json على فرع main فقط. المعاينة لا تنشر شيئًا.
